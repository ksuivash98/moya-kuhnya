# Работа над «Моей кухней»

Работайте в существующей рабочей копии. Не создавайте Git worktree без явного запроса. Сохраняйте пользовательские изменения и секреты.

Разрабатывайте только запрошенный этап. Не имитируйте будущие функции и пользовательские данные. Интерфейс на русском. Общие данные — Supabase, семейная изоляция — PostgreSQL RLS; роли не берутся из клиентской метадаты. Секреты не должны попадать в клиентский bundle или Git.

Перед изменениями проверяйте ветку, git status и подключённый origin. После изменений запускайте typecheck, релевантные тесты и сборку. Проверяйте серверные правила доступа при изменении схемы.

По инструкции пользователя готовые проверенные изменения нужно закоммитить с понятным русским названием и отправить в подключённый GitHub, если права позволяют. Перед отправкой fetch/ls-remote и проверка чужих изменений обязательны. Не используйте force push. По возможности создайте PR; PR не означает обновление main. В отчёте укажите репозиторий, ветку, хеш, проверки, результат push и ссылку/статус PR либо точную причину блокировки.
